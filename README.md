# LEDsRepair CRM

Een compacte, browsergebaseerde CRM/werkorderapp voor LEDsRepair.

## Functionaliteit

- Dashboard met werkorderstatussen en deadlines
- Reparaties/werkorders beheren
- Klanten en leveranciers beheren
- CSV-import met slimme kolommapping
- Leverancier-specifieke mappings én globale aangeleerde mappings
- Automatische herkenning van veelvoorkomende kolomnamen
- Lokale persistente opslag in de browser
- JSON-back-up en herstel
- Responsive interface voor desktop, tablet en mobiel

## Hosting

De applicatie is statisch en wordt via GitHub Pages gepubliceerd vanuit `main` met GitHub Actions.

> De huidige MVP bewaart gegevens lokaal in de browser. Voor echte multi-user werking en centrale dataopslag is in een volgende stap een backend/database nodig.
